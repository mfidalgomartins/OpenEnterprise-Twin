# v0.5 Secure and Governed Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a publicly verifiable v0.5 baseline with no known high-severity
locked dependency findings, explicit readiness and operational evidence,
current documentation, and protected GitHub change control.

**Architecture:** Keep the current modular monolith. Add small API-edge
observability and health components that depend only on bounded application
state, expose safe metadata through typed contracts, and preserve the existing
analytics/domain import boundaries.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Pydantic 2, React 19,
TypeScript 6, Vite 8, Vitest, Playwright, GitHub Actions.

## Global Constraints

- Production configuration remains fail-closed.
- No response, log or metric may expose credentials, raw datasets or business
  payloads.
- Metric labels are limited to HTTP method, registered route template and
  status family.
- `/health` remains a dependency-free liveness probe.
- `/ready` returns `503` when PostgreSQL or artifact storage is unavailable.
- `/api/v1/system/info` and `/api/v1/system/metrics` require the normal
  authenticated principal.
- Every behavioural change follows red-green-refactor.
- The locked npm and Python audits must exit zero at high severity.
